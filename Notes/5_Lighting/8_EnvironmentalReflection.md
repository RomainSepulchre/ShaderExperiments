## What is Environmental reflection ?

Contrary to the specular reflection that are only generated by the main light source, ambient reflections are generated by each light ray hitting a surface, including bouncing from all angles.

Of course this means that calculating those type of reflections in real-time use a lot of GPU power. To avoid that we can use a cubemap texture to apply pre-calculated reflections. Inside Unity we can use a reflection probe to generate this reflection cubemap.

## How to calculate environmental reflection ?

$ambientReflection = reflectionIntensity * reflectionCubemapSample * (cubemapLODLevel * reflectionExposure)$

To calculate environmental reflection we need to sample a cubemap by using a reflection vector that is simply the view direction reflected across the surface normal.

>⚠️ If we want the reflection to face the correct way we need to inverse the view direction vector before calculating the reflected vector otherwise the reflections will be upside down.

```c#
float3 AmbientReflection(samplerCUBE colorRefl, float reflectionInt, half reflectionLod, float3 normal, float3 viewDir, float reflectionExp)
{
    viewDir = -viewDir; // we need to negate view dir otherwise reflections are upside down
    float3 reflection_world = reflect(viewDir, normal); // reflect(): reflect a vector using another vector as symmetry axis
    
    // sample cubemap with a specified level of details (LOD level is W component of the sample coordinates)
    float4 cubemap = texCUBElod(colorRefl, float4(reflection_world, reflectionLod));
    
    return reflectionInt * cubemap.rgb * (cubemap.a * reflectionExp);
}
```

## Implement environmental reflections in a shader

So, if we want to add environmental reflection to our shader we need to get 6 informations:
- a *cubemap* to sample
- the *intensity of the reflection*
- the *cubemap LOD level*
- the *normal of the surface*
- the *direction of the view*
- the *exposure of the reflection*.

We can also add a *reflection metallic* value to control the shininess of the reflection and emulate metallic surface.

### Cubemap, reflection intensity, reflection LOD level, reflection exposure, reflection metallic

Those 5 parameters are properties that we need to add to our shader.

```c#
Properties
{
    _MainTex ("Texture", 2D) = "white" {}
    
    // Ambient Reflections properties
    _ReflectionTex ("Reflection Texture", Cube) = "white" {}
    _ReflectionInt ("Reflection Intensity", Range(0,1)) = 1
    _ReflectionMet ("Reflection Metallic", Range(0,1)) = 0
    [IntRange]_ReflectionLod ("Reflection Level of detail", Range(1,9)) = 1
    _ReflectionExp ("Reflection Exposure", Range(1,3)) = 0
}
```

We also need to declare a connection variable inside CGPROGRAM to be able to use the properties later in the code.

```c#
CGPROGRAM
// Pragma and include
...

// Appdata and v2f struct
...

// Connection variables
samplerCUBE _ReflectionTex;
float _ReflectionInt;
float _ReflectionMet;
half _ReflectionLod;
float _ReflectionExp;

// AmbientReflection(), vert() and frag()
...

ENDCG
```

### Surface normal and view direction (world-space)

#### Add inputs and outputs

If we want to be able to get the normal we need to include it's semantic in the vertex input and output. To calculate the view direction we also need the vertex position in world-space, it's already declared in the inputs so we only need to add it in the outputs.

In the inputs (`appdata` struct), we declare a `float3` named *normal* and we bind it to the semantic `NORMAL`.

```c#
struct appdata
{
    float4 vertex : POSITION;
    float2 uv : TEXCOORD0;
    float3 normal : NORMAL; // Get Normal
};
```

In the outputs (`v2f` struct) we need to declare two `float3` to pass the normal and the vertex position to the fragment shader. Since we will convert them world-space inside `vert()` we call them `float3` *normal_world* and *vertex_world* and we bind them to the semantic `TEXCOORD1` (`NORMAL` is not available as an output semantic) and `TEXCOORD2`.

```c#
struct v2f
{
    float2 uv : TEXCOORD0;
    UNITY_FOG_COORDS(1)
    float4 vertex : SV_POSITION;
    float3 normal_world : TEXCOORD1; // Pass normal (in world-space) to fragment shader
    float3 vertex_world : TEXCOORD2; // Pass vertex position (in world-space) to fragment shader
};
```

Finally, inside `vert()` we convert the normal and vertex position to world-space and pass it to the fragment shader.

```c#
v2f vert (appdata v)
{
    v2f o;
    o.vertex = UnityObjectToClipPos(v.vertex);
    o.uv = TRANSFORM_TEX(v.uv, _MainTex);
    UNITY_TRANSFER_FOG(o,o.vertex);
    o.normal_world =  UnityObjectToWorldNormal(v.normal); // UnityObjectToWorldNormal() is a UnityCG.cginc function that does the normal object to world-space conversion
    o.vertex_world = mul(unity_ObjectToWorld, v.vertex); // convert vertex position to world-space
    return o;
}
```

#### Calculate view direction

To calculate the view direction in the fragment shader we substract the vertex position to the camera position (both in world-space). To get the position of the camera in world-space we use the internal variable `_WorldSpaceCameraPos`.

```c#
float3 viewDir = normalize(_WorldSpaceCameraPos - i.vertex_world); // Calculate view direction using camera position
```

>⚠️ `_WorldSpaceCameraPos` is initialized inside UnityCG.cginc so we don't need to declate it as a uniform variable to use it.

UnityCG.cginc also provide `UnityWorldSpaceViewDir()`, you pass the vertex position (in world-space) as argument and it return the view direction,

```c#
 half3 viewDir = normalize(UnityWorldSpaceViewDir(i.vertex_world)); // UnityWorldSpaceViewDir() is a UnityCG.cginc function that calculate view direction from vertex world position
```

### Calculate and apply environmental reflection

Now that we have everything we need, we can calculate and apply the environmental reflection inside the fragment shader.

```c#
fixed4 frag (v2f i) : SV_Target
{
    fixed4 col = tex2D(_MainTex, i.uv);

    // Ambient reflection parameters
    half3 normal = i.normal_world;
    half3 viewDir = normalize(UnityWorldSpaceViewDir(i.vertex_world)); // UnityWorldSpaceViewDir() is a UnityCG.cginc function that calculate view direction from vertex world position
    
    // Calculate ambient reflection
    half3 reflection = AmbientReflection(_ReflectionTex, _ReflectionInt, _ReflectionLod, normal, viewDir, _ReflectionExp);
    
    // Apply reflection to texture
    col.rgb *= reflection + _ReflectionMet; // Use _ReflectionMet to control the shininess of the reflection and emulate metallic surface
    
    UNITY_APPLY_FOG(i.fogCoord, col);
    return col;
}
```

Since reflection are a lighting pass, we also need to add a tag to configure the render path

```c#
Tags {
    "RenderType"="Opaque"
    "LightMode"="ForwardBase" // configure the render path to forward base
}
```

### Use UNITY_SAMPLE_TEXCUBE to add scene environmental reflection

In the previous example we used a specific cubemap, however it's also possible to automatically use the environmental reflection from our scene. For example, if we use a skybox we can use it as a cubemap directly in the shader without having to generate a dedicated cubemap texture.

```c#
    fixed4 col = tex2D(_MainTex, i.uv);

    // Calculate reflection direction
    half3 reflect_world = reflect(-viewDir, normal); // inverse view dir to prevent upside down reflections

    // Ambient reflection parameters
    half3 normal = i.normal_world;
    half3 viewDir = normalize(UnityWorldSpaceViewDir(i.vertex_world)); // UnityWorldSpaceViewDir() is a UnityCG.cginc function that calculate view direction from vertex world position
    
    // Sample default reflection cubemap
    // -> UNITY_SAMPLE_TEXCUBE macro sample the data using the reflection coordinates
    // -> unity_SpecCube[n] contains the data of Unity default reflection probe
    half4 reflectionData = UNITY_SAMPLE_TEXCUBE(unity_SpecCube0, reflect_world);
    
    // Decode the color in HDR using DecodeHDR() (is part of UnityCG.cginc)
    half3 reflectionColor = DecodeHDR(reflectionData, unity_SpecCube0_HDR);
    
    col.rgb *= reflectionColor;

    UNITY_APPLY_FOG(i.fogCoord, col);
    return col;
#endif
